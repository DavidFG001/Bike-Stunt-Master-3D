# Bike Stunt Master 3D

A starter browser-based 3D motorcycle stunt game prototype for mobile and desktop.

## Run it
This project uses Three.js as an ES module from a CDN, so it needs an internet connection and a local web server (opening `index.html` directly may not work).

The easiest option is to upload the files to a GitHub repository and enable GitHub Pages, or use a static hosting service.

## Controls
- Mobile: use ◀ / ▶ to steer, JUMP to jump, RIDE to start.
- Computer: Left / Right arrows to steer, Space to jump, R to restart.

## Project structure
- `index.html` - game page
- `src/game.js` - 3D scene and game logic
- `src/style.css` - interface and responsive layout
- `assets/` - reserved for models, textures and sounds

This is an early playable prototype. Physics, bike models, stunt animations, collision handling and level design can be expanded in later versions.
